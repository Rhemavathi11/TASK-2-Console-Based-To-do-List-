# Console Based To-Do List App

## 📌 Description

This is a Python Console-Based To-Do List Application developed as part of my Python Internship Task 2.

The application allows users to manage daily tasks through a simple menu-driven interface. Tasks are stored in a text file, allowing data to persist even after the application is closed.

---

## 🚀 Features

* Add new tasks
* View all tasks
* Remove completed tasks
* Store tasks in a text file
* Automatically load saved tasks
* User-friendly menu interface
* Input validation and error handling
