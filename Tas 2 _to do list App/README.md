# Console Based To-Do List App

## Description
This is a Python console-based To-Do List application created as part of my Python Developer Internship Task 2.

The app allows users to add, view, and remove tasks. It also stores tasks in a text file so that tasks are saved even after the program is closed.

## Features
- Add new tasks
- View all tasks
- Remove tasks by task number
- Save tasks in `tasks.txt`
- Load saved tasks automatically
- Invalid input handling
- Console menu system

## Technologies Used
- Python
- VS Code
- PowerShell

## Concepts Used

- Conditional Statements
- File Handling
